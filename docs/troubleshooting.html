Troubleshooting

The History says "No saves yet"

The saver runs only in layouts that have its floating entry (Install). Check the layout you have open, then wait a minute.

A program did not come back after a reboot

  • It is not on the allowlist; the notification lists it. Run it by hand.
  • It started less than a minute before the machine went down, so no save had it yet.
  • Herdr was closed when the machine went down: saves only happen while the window is open.

An agent came back as a shell

Its conversation id was not known (no hook for that agent), or Herdr's integrations list no resume command for it. Open the pane's details in the History: it says which.

A restored tab has a different split

Herdr does not tell mods a tab's split shape, so a rebuilt tab stacks its panes. Tabs that were never closed keep their layout.

Not verified yet

  • Linux and Windows paths: the mod ran on macOS only.
  • Agents other than Claude Code in a live window: their resume commands come from Herdr's documentation.
