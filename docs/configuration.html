Configuration

Agents

An agent is resumed when two things are known: its resume command and its conversation id. These commands come from Herdr's own integrations:

AgentResume command
Claude Codeclaude --resume <id>
Codexcodex resume <id>
Copilot CLIcopilot --resume=<id>
OpenCode, Kimi, Kilo<agent> --session <id>
Cursor Agentcursor-agent --resume <id>
Grok, Hermes, Qoder, Droid, Devin, Qwen<agent> --resume <id>
Antigravity, Letta<agent> --conversation <id>
OMPomp --resume=<id>
MastraCodemastracode --thread <id>

Others (Pi, Gemini, Amp, ...) are listed in the notification and stay a shell. The id comes from Claude Code's own records, or from the terminal label session-restore.session that hooks/session-restore-hook.sh sets for any agent.

Programs that come back

nvim vim vi lazygit less htop btop yazi, with their arguments, in their folder. Anything else is listed and left alone: rerunning a command blindly (rm, git push, a dev server) is how restore tools do damage.

Values in the code

NameValueWhat it does
HOMEmods/session-restoreThe folder name; the one place it is written.
REVsession-restore.revShared value the saver bumps so an open History reloads.
SAVE_EVERY_MS60000How often the state is saved (kept only when it changed).
KEEP_ALL_HOURS48Every distinct save from these last hours is kept.
KEEP_DAYS30Then the newest save of each day, for these days.
KEEP_MIN10The newest saves always kept, and pinned ones.

Files

  • <Herdr home>/session-restore/snap-<time>.json: the saves, a few KB each.
  • index.json (the timeline), pins.json (pinned saves), state.json (the restart already handled).

Keys

keys.json binds ctrl-shift-o to mod.open:session-restore. Bind another key to that action if you prefer.
