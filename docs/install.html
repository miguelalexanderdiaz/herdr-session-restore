Install

One command

macOS and Linux

curl -fsSL https://raw.githubusercontent.com/miguelalexanderdiaz/herdr-session-restore/main/install/install.sh | sh

Windows (PowerShell)

irm https://raw.githubusercontent.com/miguelalexanderdiaz/herdr-session-restore/main/install/install.ps1 | iex

It says what the mod reaches, asks, copies mods/session-restore/ into Herdr's home (an older copy is backed up first), merges keys.json (asking before it replaces a key you use) and runs herdr-app check.

Add the saver to your layouts

Herdr only runs a mod where a layout places it. So add this entry to the root node's "floating" list in each layouts/<name>.json you use (it draws nothing):

{ "id": "session-restore-bg", "content": { "mod": "session-restore", "props": { "role": "background" } }, "edge": "bottom", "align": "end" }

Herdr's own layouts (main, terminals) are read-only; clone one first:

herdr-app do layout.clone '{"name":"main","as":"my-main"}'

Saves then appear in <Herdr home>/session-restore/ within a minute.

Optional: if a layout has a side panel stack, add { "id": "history", "type": "block", "content": { "mod": "session-restore" } } as one of its children to keep the History there too.

Agents' conversation ids

Claude Code needs nothing: it keeps a record per running process. Any other agent is resumed once its session-start hook runs hooks/session-restore-hook.sh, which labels the Herdr terminal with the hook's session_id. Copy it next to your Herdr home and point the agent's hook at it; snippets/claude-hooks.json shows the shape for Claude Code (a backup there).

Old screen text (optional)

Herdr can show each terminal's last screen above the new shell after a reboot. Add this line to ~/.config/herdr-core/config.toml:

restore_screen = true

By hand

  1. Copy mods/session-restore/ into <Herdr home>/mods/.
  2. Merge keys.json into yours.
  3. Add the saver to your layouts (above).
  4. Run herdr-app check <Herdr home>/mods/session-restore.

Uninstall

curl -fsSL https://raw.githubusercontent.com/miguelalexanderdiaz/herdr-session-restore/main/install/install.sh | sh -s -- --uninstall

Then remove the floating entry from your layouts, and delete <Herdr home>/session-restore/ if you no longer want the saves.
